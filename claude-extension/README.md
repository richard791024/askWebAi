全网唯一的一键多 AI 群发与实时打字流同步聚合插件。

---

## 📦 极简安装指南

1. **下载源码**：将本项目下载并解压到文件夹 `ai-omni-dashboard-core`。
2. **开启模式**：浏览器地址栏输入 `chrome://extensions/`，打开右上角 **“开发者模式”** 开关。
3. **加载插件**：点击 **“加载已解压的扩展程序”**，选择刚刚的文件夹即可。

---

## 💡 极简使用流程

1. **准备网页**：在浏览器标签页中打开 ChatGPT、Claude、DeepSeek、Gemini、Grok 并保持正常登录状态。
2. **启动控制台**：点击浏览器右上角插件图标，进入 **AI Omni Dashboard** 面板。
3. **一键发射**：在中央全局输入框中输入问题，点击“全弹发射”或按下 `Enter`。
4. **实时同步**：无需手动切换页面，五个 AI 的打字机流式回复会实时在面板中同步回传。

---

## 🛠️ 技术踩坑与核心解决方案

为了应对大厂复杂的前端防护和富文本框架，本项目采用了以下底层技术围剿方案：

| 坑点 | 原因 | 解决方案 |
| :--- | :--- | :--- |
| **发送按钮无反应** | 框架屏蔽 JS 注入 | 使用原生 `execCommand` 物理注入文本，强行激活输入框状态机。 |
| **打字流不同步** | DOM 结构动态变动 | 内置 `MutationObserver` 与靶向过滤器，实时监听节点变化。 |
| **回复含乱码/脏数据** | 混入思考框与按钮 | 采用内存克隆与暴力清洗技术，剔除思考箱与追问按钮，仅回传纯净文本。 |
| **上下文连接失效** | 页面重载导致失去连接 | 内置安全心跳机制 `sync_alive`，实时自愈连接。 |

## 🚨 常见问题

* **Q: 某家 AI 没有反应怎么办？**
  * A: 首先检查该 AI 网页是否已正确打开并登录。若已打开但无反应，在对应 AI 的原网页按下 `Ctrl + F5` 强制刷新该页面即可。
* **Q: 为什么会有乱码？**
  * A: 若插件更新滞后于 AI 官网改版，请提交 Issue。目前插件已对各大平台做了深度清洗。
* **Q: 安全吗？**
  * A: 插件纯本地运行，所有数据仅在你与大厂服务器之间传输，不经过第三方中心。
